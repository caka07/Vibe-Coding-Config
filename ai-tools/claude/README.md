# Claude Code

Use these as templates for `${HOME}/.claude/`:

- `settings.json.template` -> `${HOME}/.claude/settings.json`
- `settings.local.json.template` -> project-local or user-local permissions, if needed
- `plugins.md` -> plugin reinstall checklist

Do not migrate:

- `.claude.json`
- `projects/`
- `sessions/`
- `history.jsonl`
- `file-history/`
- `session-env/`
- `paste-cache/`
- plugin caches

Keep API keys out of Git. Replace placeholders only on the target machine.
